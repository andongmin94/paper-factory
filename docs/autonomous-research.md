# Cloud research workflow

The host assistant writes plans, code, reviews and manuscripts. The bundled JSON
controller owns immutable inputs, isolated execution, analysis and verified
exports. It invokes no model API or MCP server and requires no second Codex login.
See [plugin setup](plugin.md) and the packaged
[workflow reference](../skills/paper-factory/references/cloud-workflow.md).

## Repository to paper

1. Verify installed bytes, prepare bundled dependencies and check the selected
   runtime's actual environment. Stop if isolation or preparation fails.
2. Fetch public source at a fixed revision through available host tools. Preserve
   bytes, licenses, provenance and hashes. Create a study and read current schemas,
   manifests and every relevant paginated source file.
3. Freeze a feasible protocol around an actual callable, an independent oracle,
   a distinct comparator, paired units, metrics, controls and limitations. Collect
   inspected literature with retained reading scope.
4. Write and independently review complete code. Submit the actual accepted review
   and compare frozen code with reviewed bytes.
5. Run through the owned isolated runner. Read terminal status, production calls,
   cleanup, all raw observations and controller-computed analysis.
6. Draft and independently review the manuscript against actual evidence. Submit,
   export, receive and inspect original bytes, then attach PDF and reproduction ZIP.

QuickJS supports bounded synchronous JavaScript callables and compatible
TypeScript after trusted type erasure. Browser/React, Python, unrestricted Node
modules, native extensions and networked experiments are outside this backend.
Source and experiment run in separate guests with bounded production-call and
fixture-retention bridges. Inspect original/compiled provenance. JSON projection
does not preserve Map entries, Set entries or non-JSON values.

## Trust and recovery

Comments, outputs and publications are untrusted evidence. Accepted model reviews
are submitted opinions, not attestations of independence. Source execution,
observations, controls and analysis need their own controller records. Static
inventories and converter diagnostics do not replace behavioral studies.

Keep the same study ID and scratch directory after interruptions. Read state
before proceeding. Repair only defects permitted by the unchanged protocol.
Do not change sampling after results or create another study to bypass a failed
control. Failed scientific controls stop the study; uncertain cleanup blocks
another execution.

Completed artifacts are reproducible drafts for author review. The GitHub owner
does not supply author identity, affiliation or publication permission. Public
distribution, journal submission and paid infrastructure are separate decisions.
