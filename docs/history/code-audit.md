# Cloud plugin verification

Verify installed package bytes and actual execution separately. Local tests,
archived diagnostics, accepted reviews and converter PDFs do not establish a
completed Cloud research paper.

## Package and runtime

Check the skills-only manifest and exact resource inventory hashes. Provision
missing dependencies from bundled, hash-pinned wheels without a package index.
Record the actual interpreter and host-provided dependencies; do not claim
universal Cloud compatibility.

Require a fresh successful QuickJS environment check and confirmed owned-worker
termination. Bundled diagnostic reports remain build inputs. Verify unavailable
host filesystem/network APIs, read-only bridges, separate production and
experiment memories, and bounded heap, linear memory, time, output and dispatches.
Guest limits do not establish kernel-enforced host RSS limits.

For TypeScript, inspect original and compiled hashes and the actual transformer
and options. Execution inside QuickJS is not native Node TypeScript execution.

## Research and delivery

Read current schemas, complete paginated source/code and frozen hashes. Review
actual submissions independently. Require actual source-call receipts, raw
fixture bytes and the complete paired observation matrix.

Recompute analysis from observations. Failed scientific controls are terminal,
including when the worker also fails. Preserve valid returned evidence from
failed executions. Uncertain cleanup retains worker identity and prevents another
execution until cleanup is confirmed.

Review manuscripts against actual observations, analysis and inspected
literature. Placeholders and citations must resolve to retained evidence.
Reopen exported PDF/DOCX, verify conversion receipts and every reproduction archive
member. Receive original artifact bytes, recompute SHA256 and size, inspect the
generated pages, and attach actual files. Artifact IDs and base64 are not download
links.

Report the specific package, host, commands and evidence of the current run.
Distinguish mocks, local Wasm tests, actual Cloud execution, review opinions,
verified exports and successfully delivered attachments.

## Publication

Private upload and completed research do not establish public installation,
redistribution rights, authorship, novelty, journal suitability or publication.
Public posting and paid infrastructure remain separate actions.
