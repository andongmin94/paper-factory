# 근거·공식 출력·최종 준비 오류 수정

2026-10-30. 현재 스킬과 도구를 점검해 재현한 오류를 수정했다. 새로운 연구 단계·자동 평가·외부 의존성을 추가하지 않았다. 원고의 실제 기여와 근거로 투고 적합성을 판단하는 기준, 독립 전체 평가 최대 한 번과 자동 반복 금지는 유지한다.

## 수정 내용

| 문제 | 수정과 회귀 검증 |
| --- | --- |
| 그림이 없는데도 변환 성공 | 실제 Pandoc이 없는 그림을 설명 문구로 바꾸고 성공 종료하는 것을 재현했다. 경고가 있는 변환은 실패 처리한다. 오류와 부분 출력은 진단 대상으로 남기고 정상 출력으로 쓰지 않는다 |
| 손상된 래스터 이미지가 경고 없이 삽입됨 | 실제 DOCX에 들어간 일반 래스터 리소스의 구조를 기존 Pillow로 확인한다. 정상 상대경로 그림은 유지하고, 없는 PNG와 이미지가 아닌 PNG는 성공 결과를 반환하지 않는다. 벡터 형식 전체나 시각적 충실도를 보증하는 검사는 아니며 전체 페이지 검수는 계속 필요하다 |
| 먼저 확인한 근거가 나중에 바뀌어도 일치 판정 | 각 원자료의 동일 바이트에서 해시와 인용을 얻고 여러 인용에서 그 스냅샷을 재사용한다. 모든 원자료를 마지막에 재확인한다. 앞서 읽은 파일 변경과 누락 파일의 생성은 보고서를 쓰기 전에 오류 처리한다 |
| 코드 예제를 잘못된 인용으로 판정 | 편집 도구의 중복 코드 파서를 제거하고 기존 공통 파서를 재사용한다. 더 긴 닫기 구분자와 백틱을 포함한 인라인 코드의 가짜 인용은 무시하고 이후의 실제 인용은 검사한다 |
| 약력 검사 누락을 중복 행으로 통과 | 최종 준비 도구에서 저자 정보 연결 검사와 약력 검사가 각각 정확히 한 번 있어야 한다. 어느 한쪽을 다른 쪽의 중복 검사로 대체해도 준비 완료가 되지 않는다 |
| 평가서에 다른 Word/PDF 해시가 명시되어도 현재 평가로 판정 | 평가서의 선택적 DOCX/PDF 해시를 실제 선택 파일과 대조한다. 불일치하면 현재 평가와 준비 완료로 표시하지 않는다. 원고만 평가한 기록에 출력 검수를 새로 주장하거나 요구하지 않는다 |

## 검증 범위

전체 테스트 **224개 통과**, `compileall` 및 원본 스킬 검증기 통과. 실제 설치된 Pandoc으로 정상 상대경로 그림·코드 예제와 누락/손상된 그림 사례를 검사했다. 최종 준비 판정과 동시 파일 변경 검증에는 격리된 합성 입력을 썼다. 실제 사람의 사실·승인이나 새로운 실험을 만들어 내지 않았다.

기존 연구 자료와 산출물은 작업 전 해시 목록을 만들고 작업 후 대조한다. 보존 대상은 과거 앱 자료 2,206개, 연구·검증 자료 42개 폴더와 이전 ZIP·검증 문서다. 과거 값 `native_calls=19`, `native_limit=25`, `sdk_uuids=28`, `artifact_descriptors=614`는 그대로 유지하며 현재 모델 사용 총수나 새로운 호출 권한으로 해석하지 않는다.

설치본을 갱신하고 별도 배포 ZIP `output/paper-factory-skill-refinements-20261030.zip`을 만든다. 원본·설치본·ZIP의 파일별 해시, 보존 대조 결과와 실행 기록은 `output/skill-refinements-20261030/`에 보관한다. 이전 설치본과 이전 배포 ZIP도 보존한다. 연구 자료·저자 프로필·테스트·캐시는 배포에 포함하지 않는다.

이번 작업은 도구 오류와 잘못된 판정을 줄이는 개선이다. 프론트론 원고를 집필·수정·재평가하거나 대상 프로젝트 코드를 실행하지 않았다. 따라서 새 논문의 품질이나 게재 가능성 향상을 입증한 결과로 확대하지 않는다. 원격 CI 결과는 푸시 후 실제 실행 상태로 별도 확인한다.
