## 도구 검사와 발견한 결함

최종 테스트는 **64개 통과**다. 덮어쓰기 거절·원고 변경 감지·입력/기존 파일 보존·명시적 저자 정보·두 공식 템플릿·표/인용·외부 사본 실행·ORCID 공개 응답과 오류 처리를 다룬다. 저장소/설치본의 `quick_validate`와 `git diff --check`도 통과했다.

별도 에이전트는 초기 격리 사본으로 스킬 안내와 두 preflight 실행을 확인했다. 과학적 심사나 새 점수는 요청하지 않았다. 초기 사본에서 세 문제를 발견했다.

독립 ORCID helper로 사용자 ORCID 공개 endpoint를 실제 조회했다. 공개 이름과 소속 이력을 얻고 비공개/누락 이메일·약력은 누락으로 남겼다. 공개 소속을 제출용 현직으로 자동 선택하거나 저자 승인으로 취급하지 않았다. 이 조회로 기존 원고의 저자 정보를 바꾸지 않았다.
